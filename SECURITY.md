# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

OrbitSCP handles SSH private keys and passwords — please report security issues **privately**, not via public Issues.

**Preferred:** In the app → **📩 Report** (top bar) — include `Report Issue` with logs, or email **mostafijar@mail.com** with:

- Version (`Help → About` or `1.0.8`)
- OS and how you installed (deb/rpm/AppImage/dmg/exe)
- Steps to reproduce and impact

You will receive an acknowledgement within 48 hours. If you can, use `Report Issue` → `Include logs` and mention `SECURITY` in the subject.

We will coordinate a fix and credit you in the release notes if you wish.

## What to expect

- Fix in a patch release
- `SECURITY.md` and changelog note
- No public disclosure before a fix is available
